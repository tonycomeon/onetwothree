# 하나 · 둘 · 셋! 인물 퀴즈

아이패드에 나온 인물 사진을 보고 "하나, 둘, 셋" 안에 이름을 맞히는 게임.
한 사람이 3명 연속으로 맞히면 성공 (설정에서 1~5명으로 변경 가능).

## 문제 채우는 방법 (둘 중 하나)

**A. 파일로 채우기 (추천 · 100문제 한 번에)**
1. `photos/` 폴더에 사진을 넣는다. 파일 이름을 `001_홍길동.jpg` 형식으로 지으면 편하다.
2. `node make-data.js` 실행 → `quiz-data.js`가 자동으로 채워진다.
   (Node가 없으면 `quiz-data.js`에 `{ name: "이름", photo: "photos/파일명" }`을 직접 적어도 된다.)

**B. 아이패드에서 바로 채우기**
게임 화면 → "문제 관리" → "사진 추가"로 여러 장 선택 → 이름 칸 입력
(또는 "이름 한 번에 입력"에 한 줄에 한 명씩 붙여넣기). 사진은 그 기기 브라우저에 저장된다.

## 아이패드에서 여는 법
폴더째 Netlify Drop(app.netlify.com/drop), Vercel, GitHub Pages 등에 올리고 Safari로 접속.
Safari 공유 → "홈 화면에 추가"로 열면 주소창 없이 전체화면으로 쓸 수 있다.

## 진행 방법
- "게임 시작" → "도전 시작" → 사진이 뜨면서 하나·둘·셋 카운트
- 진행자가 ○ 정답 / ✕ 오답 터치 ("셋"이 끝나도 판정 전까지 기다림. 설정에서 자동 오답 가능)
- 정답이면 다음 사진 자동 진행, 오답이면 정답 공개 후 다음 도전자
- 한 번 나온 사진은 다시 안 나옴 → 홈의 "나온 문제 초기화"로 리셋
- 키보드: Space 시작/다음, → 또는 O 정답, ← 또는 X 오답, S 건너뛰기
